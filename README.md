# TrueEyeballproject

## Features
- Hand movement = cursor movement
- Left eye blink = left click
- Right eye blink = right click
- Both eyes closed = pause cursor

## Required
- Python 3.11
- face_landmarker.task file in project root

## Install
py -3.11 -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install mediapipe==0.10.32
python main.py

## Run
python main.py
